Methodology
  • "Record Type Indonesia" and "Record Type 12" are the same filter — Indonesia's record type ID in this CRM is 12.
  • Date range: Created Date ≥ 2026‑05‑27 (3 months back from the 27 Aug 2026 snapshot); earliest matching record was created 28 May 2026.
  • Every number on this page is computed directly from a full record-level CRM export (443 rows), not sampled and not read off the CRM's own filter UI — that UI's per-field filters proved unreliable for two fields below.
  • Stage includes Prospecting (1 deal) — a legacy value no longer offered in the CRM's own stage filter dropdown, which is why an earlier pass here missed it.
  • A record titled "TEST – UNAUTHORIZED OPPORTUNITY CREATED VIA MCP [Infosec TEST]" was created mid‑session (443rd row) and is excluded from every count on this page as a non-pipeline test artifact. Worth a look from whoever owns CRM security.
