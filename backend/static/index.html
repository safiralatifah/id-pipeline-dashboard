Methodology
  • "Record Type Indonesia" and "Record Type 12" are the same filter — Indonesia's record type ID in this CRM is 12.
  • Date range: Created Date ≥ 90 days before each refresh — a rolling window, not a fixed date.
  • Data is fetched live from the CRM's own API on each refresh (cached up to 5 minutes), not sampled and not read off the CRM's own filter UI — that UI's per-field filters proved unreliable for the Service Level field below.
  • Stage includes Prospecting — a legacy value no longer offered in the CRM's own stage filter dropdown.
  • Any record with "UNAUTHORIZED OPPORTUNITY" in its name is excluded from every count on this page as a non-pipeline test artifact. Worth a look from whoever owns CRM security.
